# 《小团体花名册》B 站视频录制脚本

> 目标时长：3 分 30 秒～4 分钟
> 视频类型：项目演示 + 顺手教怎么跑起来
> 仓库：https://github.com/Roy1118/qq-coterie-roster

---

## 一、录制前准备

### 1. 录屏参数

| 项目 | 建议 |
| --- | --- |
| 分辨率 | 1920×1080（浏览器窗口最大化后 100% 缩放） |
| 帧率 | 30 fps 足够（页面无高速动画）；30/60 都行 |
| 浏览器 | Edge / Chrome，**先关掉书签栏、扩展图标、其他标签页**（Ctrl+Shift+B 隐藏书签栏） |
| 窗口 | 不要录到任务栏和桌面图标，用「窗口录制」而不是「全屏录制」 |
| 鼠标 | 开启「显示点击效果」或后期加点击高亮，操作要慢 |
| 声音 | 先录屏后配音；口播单独录，方便改稿 |

### 2. 数据准备（重要）

**先把数据同步完再开始录**，不要录等待同步的过程：

1. 提前登录，跑完 `同步群列表` + `同步全部群成员`
2. 打开概览页确认数字已经出来（本机实测：109 个群 / 45574 人次 / 42296 位独立群友）
3. 关掉 `data/roster.db` 所在窗口，别在录屏时露出数据库文件

### 3. 隐私打码（务必做）

- 群名、群号、群友昵称、群名片、QQ 号、头像**都可能暴露真实身份**
- 方案 A（推荐）：录制时先切到一个小号 QQ、或用自己建的测试群
- 方案 B：后期用马赛克/高斯模糊盖住群名和 QQ 号，**不要只盖一半**
- 手机扫码那一幕**千万别拍到二维码**（二维码等于登录凭证，扫了就能登你的号）
- 头像建议整体模糊；如果糊得太麻烦，就用测试群数据录演示片段

## 二、分镜脚本

### 镜头 1｜钩子（0:00 – 0:15）

**画面**：概览页 hero 区，鼠标缓慢划过四个大数字（群聊数 / 独立群友 / 跨群群友 / 7 日活跃）。

**口播**：
> 我加了 100 多个 QQ 群，一直有个问题没人能回答：这 4 万多个群友里，到底谁同时在好几个群里？
> 于是我写了个小工具，把这个问题彻底解决了 —— 而且它不上传任何数据，全部跑在你自己电脑上。

**花字**：`谁和你混在同一个「小团体」里？`

---

### 镜头 2｜痛点（0:15 – 0:35）

**画面**：切到「群聊」页快速下滑群卡片列表，再切到「群友」页。

**口播**：
> 平时想过几个问题，纯靠 QQ 是查不出来的：
> 这两个群有多少人是重叠的？某个群里谁还在别的群？谁最近突然不说话了，谁又是刚进来的？
> 手动点开一个个群去对名单，一百个群对到明年。

**花字**：`重叠？潜水？新来的？QQ 不告诉你`

---

### 镜头 3｜它是什么（0:35 – 1:00）

**画面**：切到「单群透视」页，展示「跨群名单」表格 + 右侧「本群关系辐射」图。

**口播**：
> 这个工具叫「小团体花名册」。逻辑很简单：它读取你**自己已经加入的群**的成员名单，在本地算重合关系。
> 不需要群主权限、不需要管理员，普通群成员就能用。
> 完全不读聊天记录，只看得到 QQ 号、昵称、群名片、入群时间和最后发言时间这几个公开字段。

**花字**：`普通成员就能用 · 不读聊天记录 · 数据不出本机`

---

### 镜头 4｜跑起来（1:00 – 1:30）

**画面**：打开 PowerShell / 终端，逐行敲命令（**打字慢一点**，后期可 1.5 倍速），然后浏览器自动弹出页面。

**终端画面**：
```bash
git clone https://github.com/Roy1118/qq-coterie-roster.git
cd qq-coterie-roster
python app.py
```

**口播**：
> 部署是我见过最无脑的一类：只要电脑上有 Python 3.10 以上，三行命令。
> **不需要装任何第三方库** —— 没有 pip install，没有依赖冲突。
> 跑起来之后浏览器会自动打开本地地址，127.0.0.1，只允许你自己这台机器访问。

**花字**：`Python 3.10+ · 零第三方依赖 · 只监听 127.0.0.1`

---

### 镜头 5｜扫码登录 + 同步（1:30 – 2:00）

**画面**：「登录与数据」页 → 点「生成二维码」→（**把二维码区域打码**）→ 点「同步群列表」→ 点「同步全部群成员」，展示顶部进度条。

**口播**：
> 第一次用按三步走。第一步扫码登录，二维码三分钟内有效，扫它只是为了拿到 `qun.qq.com` 的会话，不会读你的聊天记录。
> 第二步同步群列表，第三步逐群拉成员。群多的时候慢一点很正常，它每个群之间会自动间隔一下，避免被腾讯限流，可以随时点停止，也能「同步未完成的群」接着跑。

**花字**：`① 扫码登录 → ② 同步群列表 → ③ 同步全部成员`

**后期提醒**：同步进度的真实等待时间剪掉，改成快进 + 进度条加速。

---

### 镜头 6｜五个分析页（2:00 – 3:00）

**画面**（每个页面 ~10 秒，操作要慢）：

1. **概览**：hero 数字 + 「跨群最多的人」排行榜 → 点一个人
   > 概览页直接把四个核心数字摆出来，跨群最多的人排在最上面，点一下就能看 TA 的完整轨迹。

2. **单群透视**：选一个群 → 勾上「只看跨群成员」→ 指一下「桥梁成员」
   > 单群透视是我最常用的。选一个群，能看这群人还在哪些群、在别的群用什么群名片。
   > 有个数字叫「桥梁成员」——除了本群还在 3 个以上其他群的人，他们通常就是把不同小团体连起来的关键节点。

3. **交叉分析**：勾选 2 个群 → Venn 三个数字 → 再勾第 3 个群 → Jaccard
   > 交叉分析是原生的需求：两个群多少人是重合的？选两个群，左边只在这群、中间两个都在、右边只在另一个。
   > 选三个群以上，就换成共同成员数、去重总人数和 Jaccard 重合度。名单能一键导出 CSV。

4. **群友**：搜索一个昵称 → 点进 TA 的画像
   > 群友页可以按 QQ 号、昵称、群名片搜。点开任意一个人，TA 加入的所有群、每个群的群名片、最早入群和最后发言时间全部列出来。

5. **活跃度**：切换「最近活跃 / 长期潜水 / 新入群」，改一下天数
   > 活跃度分三种视角：最近活跃的、长期潜水的、刚进群的，时间窗口从 7 天到一年随便调。

**花字**：`概览 · 单群透视 · 交叉分析 · 群友 · 活跃度 · 群网络`

---

### 镜头 7｜群网络三种图（3:00 – 3:35）

**画面**：进「群网络」→ 力导向图（滚轮缩放、拖拽平移、点一个节点聚焦）→ 切「和弦图」→ 切「热力图」。

**口播**：
> 重头戏是群网络，三种画法。
> 力导向图看整体结构，节点是群、连线是两个群之间的重合人数，滚轮能缩放、拖着能平移，点一个节点就聚焦到它身上。
> 和弦图看的是「流量」，丝带越粗说明两个群之间来回跑的人越多。
> 热力图适合精确比较两两群。
> 还能调「最少共同成员」和「显示群数」，群多的时候不至于糊成一团。

**花字**：`力导向图看结构 · 和弦图看流量 · 热力图看两两重合`

---

### 镜头 8｜隐私与收尾（3:35 – 4:00）

**画面**：「登录与数据」页拉到底，停在「隐私与安全」那块绿色说明上；再快速闪一下导出按钮和表情包墙。

**口播**：
> 最后说隐私，这也是我敢自己用的原因：所有数据只写进本机的 `data/roster.db`，只请求腾讯的 `ptlogin2.qq.com` 和 `qun.qq.com`，没有任何上报、统计和云同步。
> 需要留档可以导出 CSV 或 JSON，换电脑导入 JSON 就恢复。
> 代码全部开源，仓库地址在简介和置顶评论里，链接在屏幕上。

**画面**：全屏显示仓库地址 `github.com/Roy1118/qq-coterie-roster`，配一句「点 Code → Download ZIP 就能拿到全部文件」。

**花字**：`开源 · 本地运行 · 不读聊天记录`

## 四、后期建议

| 项目 | 建议 |
| --- | --- |
| BGM | 用平台自带曲库或无版权音乐，**别用流行歌**，会被版权投诉下架 |
| 节奏 | 同步等待、页面加载全部剪掉；操作片段 1.2～1.5 倍速 |
| 花字 | 每个功能页左上角固定一个页面名标签，观众不容易迷路 |
| 打码 | 群名/QQ 号全程模糊；二维码那一幕整块盖住 |
| 封面 | 用概览页 + 力导向图做左右分屏，标题压两行（见文案文档） |

按上面的口播稿顺序粘贴即可。注意这几个专有名词的字幕写法：

- `qun.qq.com`（不要写成 qunqq.com）
- `Jaccard`（不是 Jaccar / Jacard）
- `r.o.s.t.e.r` → 写成 `roster.db`
- `127.0.0.1`（不是 127.0.01）
- 项目名统一写「小团体花名册」
