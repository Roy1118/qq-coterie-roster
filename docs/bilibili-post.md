## 三、简介（直接复制）

```text
100 个 QQ 群、4 万位群友，到底谁同时在好几个群里？

这个工具叫「小团体花名册」，读取你自己已加入的群的成员名单，在本地算出跨群重合、活跃度、群关系网络。

✅ 只要 Python 3.10+，零第三方依赖，三行命令跑起来
✅ 普通群成员就能用，不需要群主/管理员权限
✅ 不读聊天记录，只看 QQ 号、昵称、群名片、入群时间、最后发言时间这些公开字段
✅ 数据只写本机 SQLite，只请求腾讯域名，没有任何上报和云同步

📦 开源仓库（点 Code → Download ZIP 就能拿到全部文件）：
https://github.com/Roy1118/qq-coterie-roster

⏱ 时间轴
00:00 我想解决的三个问题
00:35 它是什么 / 权限边界
01:00 三行命令跑起来
01:30 扫码登录 + 同步数据
02:00 概览 & 单群透视
02:25 交叉分析（两个群的重合度）
02:45 群友检索 & 活跃度
03:00 群网络：力导向图 / 和弦图 / 热力图
03:35 隐私说明与收尾

💻 环境
Python 3.10+（Windows / macOS / Linux 都可以）

git clone https://github.com/Roy1118/qq-coterie-roster.git
cd qq-coterie-roster
python app.py

⚠️ 使用提醒
· 只能看到你自己已加入的群，看不到没加入的群
· 依赖 qun.qq.com 的网页接口，接口变动时可能需要适配
· 导出的 CSV / JSON 含群友 QQ 号，请勿随意分享
· 请遵守 QQ 用户协议和各个群的群规
· 本项目与腾讯官方无关

#QQ群 #Python #开源 #数据分析 #本地运行 #群友分析 #数据可视化
```

## 七、评论区预设回复

| 观众会问 | 你怎么回 |
| --- | --- |
| 会不会封号？ | 用的是网页端接口，请求频率做了间隔控制，不读聊天记录。但任何第三方工具都有风险，请自己判断，只在你自己的号上用。 |
| 能看没加入的群吗？ | 不能。只能读你自己已加入的群，这也是它的权限边界。 |
| 支持手机吗？ | 项目本身是本地 Web 服务，可以在电脑上跑、手机连同一 WiFi 访问，但默认只监听 127.0.0.1，要改 `--host` 才行。 |
| 为什么不读聊天记录？ | 一是不需要（重合分析只用成员名单），二是读取聊天内容涉及隐私和协议问题，这个工具刻意不做。 |
| 能打包成 exe 吗？ | 在我的计划里，目前要先装 Python。 |
| 数据会上传吗？ | 不会。代码开源可以自己看，只请求 `ptlogin2.qq.com` / `qun.qq.com`，数据全部写本机 SQLite。 |
| 群名/QQ 号怎么打码的？ | 视频里用测试群录的，真实数据做了模糊处理。 |
